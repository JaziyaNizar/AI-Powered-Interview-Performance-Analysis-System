# 🤖 AI-Powered Interview Performance Analysis System

## 🚀 Project Overview

An AI-powered interview performance analysis system that evaluates a candidate's visual and speech-based communication during an interview using **Computer Vision, Speech Recognition, and real-time WebRTC processing**.

### Key Features:

- **Eye Contact Analysis:** Tracks visual attention toward the camera using **MediaPipe**.
- **Facial Expression Analysis:** Detects facial-expression patterns using **DeepFace**.
- **Head Pose Analysis:** Monitors head orientation and posture throughout the interview.
- **Speech-to-Text:** Converts the candidate's spoken response into a text transcript.
- **Speech Analysis:** Evaluates speaking pace, filler-word usage, word count, and speech fluency.
- **Performance Scoring:** Combines visual and speech indicators to generate an overall interview performance score.
- **Automated Feedback:** Provides feedback based on the candidate's detected performance indicators.
- **Deployment:** Interactive web application built using **Streamlit and WebRTC**.

## 🛠️ Installation & Usage

1. Clone the repo: `git clone https://github.com/JaziyaNizar/AI-Powered-Interview-Performance-Analysis-System.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `python -m streamlit run app.py`

## 📊 Results

The system generates a structured interview performance assessment including **eye contact, facial expression, head posture, speech fluency, speaking pace, filler-word usage, transcript, overall score, and personalized feedback**.
